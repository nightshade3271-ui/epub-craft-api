Commercial Endpoints

Ultra-clean RESTful specification built for high-throughput automated workflows.

POST /v1/epub/compile
Core

Compiles full manuscript into a binary or base64 EPUB 3 archive. Auto-generates NCX, OPF, cover art, and XHTML navigation.

Header: Content-Type: application/json
Response: application/epub+zip OR application/json (base64)
POST /v1/epub/validate
Pre-flight

Checks manuscript structure, word count, estimated reading time, and Amazon KDP pre-flight compliance before compilation.

Returns: { readyToCompile: true, stats: { totalWords, readingTime } }
GET /v1/epub/sample.epub
Instant Test

Instantly stream-downloads a demonstration EPUB 3 book for zero-configuration integration testing.

Direct download: the-art-of-strategy.epub (application/epub+zip)
GET /v1/epub/themes
Metadata

Lists all typography themes (Bookerly, Garamond, Ember, Fantasy), cover art templates, and section types.

Returns: { typographyThemes: [...], coverPresets: [...] }

Integration Snippets

Copy and paste into your backend in seconds.

curl -X POST "https://epub-craft-api.vercel.app/v1/epub/compile" \
  -H "Content-Type: application/json" \
  -H "X-RapidAPI-Key: YOUR_RAPIDAPI_KEY" \
  --data '{
    "title": "My Next Bestseller",
    "author": "Jane Author",
    "theme": "theme-bookerly",
    "coverPreset": "obsidian_gold",
    "sections": [
      {
        "title": "Chapter 1",
        "hasDropCap": true,
        "content": "
It was a dark and stormy night...
"
      }
    ]
  }' --output my_book.epub
